This directory contains the full implementation of a procedural skeletal character animation system for a 3D game engine, split across 16 documented source segments. It covers bone rendering utilities, ECS-based animation systems (via Flecs), inverse kinematics, gait and locomotion, upper/lower body procedural motion, mesh generation, and telemetry logging. Built with C++ and GLM math, the codebase targets graphics and gameplay engineers with experience in skeletal animation, ECS architecture, linear algebra, and real-time character systems.
