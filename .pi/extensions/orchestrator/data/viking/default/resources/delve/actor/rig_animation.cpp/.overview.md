# rig_animation.cpp

This directory contains the full implementation of a procedural skeletal character animation system for a 3D game engine, split across 16 documented source segments. It covers bone rendering utilities, ECS-based animation systems (via Flecs), inverse kinematics, gait and locomotion, upper/lower body procedural motion, mesh generation, and telemetry logging. Built with C++ and GLM math, the codebase targets graphics and gameplay engineers with experience in skeletal animation, ECS architecture, linear algebra, and real-time character systems.

## Detailed Descriptions

### rig_animation_1.md rig_animation_1.md — Bone Rendering Utilities
Implements `emit_strut` for wireframe triangular prism geometry and `append_bone_cage` for tapered polygonal cage meshes along bone segments. Covers stable perpendicular basis construction, ring vertex generation, flat-shaded normals, and a shared `AnimationConfig` instance.

### rig_animation_10.md rig_animation_2.md — Smooth Damp, IK Solver, Movement System
Covers geometric bone visualization helpers, a Unity-style critically-damped `smooth_damp` spring smoother, an angle-aware variant for wraparound, a two-bone analytical IK solver with pole vector support, and the `PlayerMovementSystem` for input-driven velocity updates.

### rig_animation_11.md rig_animation_3.md — Isometric Movement, Rotation, and Grounding
Details isometric input remapping, velocity smoothing, adaptive turn detection with hysteresis, chest-hip torsion simulation, look-at target blending, and the `ActorGroundingSystem` for terrain-snapping the character root.

### rig_animation_12.md rig_animation_4.md — GaitSystem: Foot Placement and Phase
Implements the ECS `GaitSystem` with one-foot-planted invariant, speed-adaptive step timing, gait phase driving arm swing and hip oscillation, turn urgency blending, and orthogonal step basis vectors for consistent foot placement during turns.

### rig_animation_13.md rig_animation_5.md — Step Sequencing and Foot Prediction
Covers turn-priority foot queuing, starvation guards, velocity-predicted foot placement via an inverted pendulum model, half-space lateral clamping, smootherstep horizontal interpolation, half-sine vertical lift arcs, and terrain-conforming height sampling.

### rig_animation_14.md rig_animation_6.md — Foot Grounding and Constraint Systems
Addresses step completion logging, planted-foot Z-axis terrain tracking, half-space corrective step triggers, and a world-lock with reach-clamp system preventing foot hyperextension via sphere trace queries.

### rig_animation_15.md rig_animation_7.md — GrabDriveSystem and IKSystem
Covers `GrabDriveSystem` translating grab state into arm IK goals with heavy-carry overlay activation, and `IKSystem` computing full skeletal joint positions including hips, spine, chest, neck, shoulders, and hip sockets using visual/chest facing vectors for torso torsion.

### rig_animation_16.md rig_animation_8.md — Arm Joint Chains and FK/IK Blending
Implements successive-breaking smooth damping across shoulder, elbow, and wrist joints; FK elbow/wrist calculation via Rodrigues rotation; and weighted lerp blending between FK and two-bone IK solutions when an `ArmIKGoal` target is active.

### rig_animation_2.md rig_animation_9.md — Leg IK, Overlay System, and LookAt
Covers shared two-bone leg IK with symmetrical knee flare, an `OverlaySystem` for additive limp/fatigue/heavy-carry joint offsets, and a `LookAtSystem` for procedural head, neck, and chest tracking.

### rig_animation_3.md rig_animation_10.md — Look-At Targeting and SkeletonFinaliseSystem
Implements yaw/pitch look-at decomposition with weighted joint distribution across HEAD, NECK, and CHEST, plus hip sway, slope-driven tilt, acceleration-based torso lean, and idle micro-motion with smooth damping.

### rig_animation_4.md rig_animation_11.md — Hip and Torso Procedural Dynamics
Details CoM lateral hip sway, hip counter-animation with roll and vertical bob, parabolic step-event hip dip, and acceleration-driven torso lean, all smoothed via `smooth_damp` across the full joint hierarchy.

### rig_animation_5.md rig_animation_12.md — Upper-Body Animation and Derived Joints
Covers lean propagation through chest/neck/head, chest counter-rotation from facing lag, idle breathing and lateral sway oscillators, idle weight shifting, and derived joint computation for ROOT, SPINE_02, HEAD_END, and clavicles.

### rig_animation_6.md rig_animation_13.md — SkeletonFinaliseSystem and RigTransformSystem
Addresses toe joint positioning, pole target computation for knee/elbow IK chains, IK goal assignment, and per-joint transformation matrix generation using `build_bone_basis` and `make_bone_mat4` with table-driven spine chain processing.

### rig_animation_7.md rig_animation_14.md — Limb Chain Bone Transforms
Implements `compute_limb_chain` using bend-plane normals via cross products, re-orthogonalization, degenerate fallback handling, and differentiated end-effector logic for legs (toe-aligned) versus arms (forearm-inherited).

### rig_animation_8.md rig_animation_15.md — Clavicle Transforms and Mesh Generation
Covers lambda-based clavicle orientation matrix computation and the `MeshGenerationSystem` procedurally generating tapered hexagonal bone cage meshes for the full humanoid skeleton with per-segment radius tapering.

### rig_animation_9.md rig_animation_16.md — Arm Mesh Generation and Animation Telemetry
Details arm bone cage mesh construction for both arms across four segments each, and the `AnimationLogSystem` capturing comprehensive per-frame JSONL telemetry including transform, gait, joint poses, balance metrics, and dynamics data.
