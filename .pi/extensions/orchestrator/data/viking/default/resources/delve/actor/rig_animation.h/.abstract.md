This directory contains the registration interface for a procedural animation system built on the Flecs Entity Component System (ECS) framework. It defines a pipeline of 11 ordered animation systems executing during the PostUpdate phase, covering the full transformation chain from player input through skeletal rigging to final mesh output. Topics include inverse kinematics (IK), procedural foot placement, terrain snapping, head tracking, secondary motion, world-space matrix computation, and JSONL telemetry logging. Suitable for graphics and gameplay engineers familiar with ECS architecture, skeletal animation pipelines, and the Flecs framework.
