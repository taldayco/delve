This directory contains the full implementation of a `RigRenderer` system for visualizing skeletal/bone structures in an isometric 3D game engine using SDL3 GPU APIs and the flecs ECS framework. It covers GPU resource management, procedural geometry generation for bones and joints, isometric projection compensation, debug visualization tools (IK goals, pole targets, tripods), and per-frame rendering orchestration. Core keywords: skeletal animation, bone rendering, isometric projection, SDL3 GPU, BasaltVertex, cylinder geometry, ECS. Suitable for graphics and game engine programmers familiar with GPU rendering pipelines, GLM math, and humanoid rig hierarchies.
