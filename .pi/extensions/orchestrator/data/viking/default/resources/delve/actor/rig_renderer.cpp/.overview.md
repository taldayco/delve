# rig_renderer.cpp

This directory contains the full implementation of a `RigRenderer` system for visualizing skeletal/bone structures in an isometric 3D game engine using SDL3 GPU APIs and the flecs ECS framework. It covers GPU resource management, procedural geometry generation for bones and joints, isometric projection compensation, debug visualization tools (IK goals, pole targets, tripods), and per-frame rendering orchestration. Core keywords: skeletal animation, bone rendering, isometric projection, SDL3 GPU, BasaltVertex, cylinder geometry, ECS. Suitable for graphics and game engine programmers familiar with GPU rendering pipelines, GLM math, and humanoid rig hierarchies.

## Detailed Descriptions

### rig_renderer_1.md rig_renderer_1.md — GPU Initialization & Cylinder Geometry

Covers the foundational setup of the `RigRenderer`: the `IsoCompensation` struct that dynamically corrects visual distortion of vertical bones in isometric projection (adjusting width scaling, equatorial ring positioning, and radial Z compression), GPU resource initialization creating a static vertex buffer at `MAX_RIG_VERTICES` capacity with a persistent transfer buffer, proper resource cleanup, and the `emit_cylinder` function for generating procedural cylindrical mesh geometry using orthonormal basis vectors with configurable radius, sides, and color.

### rig_renderer_2.md rig_renderer_2.md — Bone Oct & Sphere Geometry

Completes the `emit_cylinder` direction-dependent radial Z compensation logic and introduces two additional emitters: `emit_bone_oct`, which generates octahedral bone shapes (tail point, equatorial ring at 20% bone length, tip point) using a 4-sided pyramid structure with outward triangle winding; and `emit_sphere`, which creates UV spheres for joint pivot markers via latitude/longitude subdivision. All emitters populate `BasaltVertex` structs with position, color, sheen, and normal data.

### rig_renderer_3.md rig_renderer_3.md — Tripod, Box, Diamond & Flat Circle Primitives

Implements four additional geometry emitters used for debug and structural visualization. `emit_tripod` renders RGB-coded world-axis indicators using thin cylinders. `emit_box` generates axis-aligned cubes via 12 triangles across 6 faces with per-face normals. `emit_diamond` constructs an 8-triangle octahedron with computed cross-product normals. `emit_flat_circle` produces a fan-triangulated disk with a fixed upward-facing normal. Sheen values differ per primitive type, suggesting material differentiation across debug shapes.

### rig_renderer_4.md rig_renderer_4.md — Wireframe Box & Per-Frame Prepare Function

Implements `emit_wireframe_box`, which builds a wireframe cube from 12 thin cylinder edges mapped to cube corner vertices, and the central `prepare` function that drives per-frame rig rendering. Key topics include hip counter-animation (vertical bob and lateral drop), isometric height foreshortening applied to joint positions while preserving ground-contact joints, procedural cage mesh vertex transformation, and color-coded debug rendering of IK goals and pole targets via ECS entity iteration using flecs.

### rig_renderer_5.md rig_renderer_5.md — Full Humanoid Rig Assembly

Details the complete geometry emission sequence for a humanoid skeletal figure. Covers ground marker rendering (terrain-locked flat circles and foot trace cylinders), full bilateral leg chains from hips through toes using `emit_bone_oct`, pelvis and shoulder crossbar connections, spine and torso segments, neck and head chain, and bilateral arm chains including clavicles. Joint pivot spheres and RGB axis tripods are rendered at structural joints. Drawing order is intentional — root tethers are emitted before limbs for correct depth layering.

### rig_renderer_6.md rig_renderer_6.md — IK Debug Visuals & GPU Draw Call

Handles the final rendering stages: emitting green wireframe boxes at IK goal joints (feet and hands), orange diamond shapes at pole target joints (knees and elbows), and dashed connector lines rendered as alternating cylinder segments. Also covers the complete GPU buffer management pipeline — mapping the transfer buffer, copying vertex data, uploading via a GPU copy pass, and enforcing `MAX_RIG_VERTICES` with overflow warnings. The `draw` function binds the graphics pipeline, pushes scene uniforms to vertex and fragment stages, binds point light storage buffers, and issues the final draw call.
