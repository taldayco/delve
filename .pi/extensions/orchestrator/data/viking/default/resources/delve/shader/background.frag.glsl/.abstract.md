This directory contains a single GLSL fragment shader implementing a procedurally generated animated starfield background. The shader is built for Vulkan-compatible pipelines (GLSL version 450) and produces a multi-layered, parallax-scrolling star field without any texture lookups. It is suitable for graphics programmers and game developers working with real-time rendering, shader pipelines, and procedural visual effects. Core topics include hash-based pseudo-randomness, Gaussian falloff, sinusoidal animation, spectral star coloring, and multi-layer depth composition.
