# background.frag.glsl

This directory contains a single GLSL fragment shader implementing a procedurally generated animated starfield background. The shader is built for Vulkan-compatible pipelines (GLSL version 450) and produces a multi-layered, parallax-scrolling star field without any texture lookups. It is suitable for graphics programmers and game developers working with real-time rendering, shader pipelines, and procedural visual effects. Core topics include hash-based pseudo-randomness, Gaussian falloff, sinusoidal animation, spectral star coloring, and multi-layer depth composition.

## Detailed Description

### backgroundfrag.md background.frag.glsl — Animated Procedural Starfield Shader

This GLSL fragment shader (version 450) renders a fully procedural, animated starfield intended as a scrolling background for a 2D game or real-time application. It requires no texture assets, relying entirely on mathematical constructs to produce a visually rich star field.

**Inputs and Uniforms**
The shader receives UV coordinates per fragment and three uniform values: elapsed time (driving animation), and camera position components `cam_x` and `cam_y`. Camera position feeds into a parallax offset calculated at a factor of 0.18, causing the star field to drift subtly relative to foreground elements and reinforcing the illusion of depth.

**Hash-Based Randomness**
Two hash functions — `hash11` (scalar-to-scalar) and `hash21` (2D-to-scalar) — provide deterministic pseudo-random values. Because these are purely mathematical, star positions and properties remain stable and reproducible across frames without any texture lookups or external data, keeping the shader self-contained and portable.

**Star Coloring**
The `star_color_from_hash` function maps hash values to physically inspired stellar colors spanning the visible spectral range: blue-white for hot stars, yellow-white for sun-like stars, and orange-red for cooler stars. The distribution follows approximate spectral class probabilities, giving the starfield a naturalistic appearance rather than uniform white points.

**Multi-Layer Depth Composition**
Three separate `star_layer` calls compose the final image, each operating at a different cell grid size:
- **120-pixel cells** — sparse, larger stars representing distant bright objects
- **55-pixel cells** — medium density and radius, mid-ground layer
- **28-pixel cells** — dense, smaller stars forming a fine background layer

Each layer uses its own density threshold and star radius, and the parallax offset scales consistently across layers, producing a convincing sense of three-dimensional depth through scale and motion variation alone.

**Per-Star Visual Effects**
Individual stars are rendered with several layered visual features:
- **Gaussian core**: a tight, bright central point with smooth mathematical falloff
- **Soft glow**: a wider, lower-intensity halo surrounding the core
- **Luminosity variation**: hash-derived brightness differences between stars
- **Sinusoidal twinkling**: time-driven oscillation of brightness, with each star's phase offset by its hash value so twinkling appears independent and organic

**Intended Audience and Use**
This shader is aimed at graphics or game developers comfortable with GLSL, Vulkan descriptor set bindings, and shader pipeline integration. It demonstrates several reusable techniques — procedural placement, multi-layer parallax, Gaussian rendering, and hash-based animation — that can be adapted for other procedural background effects beyond starfields.
