# common.glsl

This directory contains a single GLSL shader header file that serves as a centralized registry for uniform variable definitions within a graphics rendering pipeline. It establishes a consistent naming convention through preprocessor macros, mapping readable constant names to shader uniform parameter locations. The file covers multiple rendering domains including time-based animation, visual effects (contour rendering, lava color), lighting systems (directional, ambient, star intensity), and depth clipping parameters. It is best suited for graphics programmers and shader developers working with OpenGL/GLSL who need a maintainable, single source of truth for uniform variable aliasing across shader files.

## Detailed Description

### common.md common.md — GLSL Uniform Variable Registry

This GLSL shader header file acts as the central hub for uniform variable definitions across the rendering system. Rather than scattering uniform declarations throughout individual shader files, this header consolidates all mappings in one place using preprocessor macros, with an include guard mechanism ensuring the definitions are never duplicated during compilation.

The file organizes its uniform definitions across several distinct rendering domains:

- **Time-based animation**: The `UNI_TIME` macro provides a consistent reference to the shader uniform responsible for driving time-dependent visual effects and animations.

- **Visual effects**: Macros covering contour opacity and lava color uniforms support specialized rendering passes, enabling stylized surface effects without hardcoding parameter locations in individual shaders.

- **Lighting parameters**: Definitions for directional light direction/intensity, ambient light levels, light color, and star intensity are all registered here, giving the lighting system a unified interface that any shader can reference by including this header.

- **Depth rendering**: Near and far clipping plane parameters are defined, supporting depth-based calculations such as linearized depth buffers, fog, or shadow mapping passes.

The primary value of this file lies in its role as a **single source of truth** for uniform aliasing. By centralizing these definitions, the codebase avoids magic numbers and inconsistent naming, making shaders easier to read, debug, and maintain. Any change to a uniform location only needs to be made in one place, and all shaders that include this header automatically reflect the update.

This file is most relevant to graphics programmers and shader developers who are familiar with GLSL, OpenGL uniform buffers, and real-time rendering pipelines. Understanding this header is a prerequisite for working with any shader in the system that relies on the defined uniforms.
