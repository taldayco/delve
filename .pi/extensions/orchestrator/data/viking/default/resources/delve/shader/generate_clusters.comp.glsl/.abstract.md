This directory contains a single GLSL compute shader responsible for generating axis-aligned bounding boxes (AABBs) used in clustered lighting systems. It is a core component of tile-based or clustered forward/deferred rendering pipelines, covering concepts such as screen-space tiling, depth slicing, NDC space conversion, and light culling acceleration structures. The shader targets graphics programmers working with Vulkan and GLSL compute pipelines who need a reference implementation for building cluster data structures that accelerate real-time light assignment and rendering.
