## Detailed Description

### generate_clusterscomp.md generate_clusterscomp.md — GLSL Compute Shader for Cluster AABB Generation

This file documents a GLSL compute shader (version 450) that forms the backbone of a clustered lighting pipeline. Its primary responsibility is to populate a buffer of axis-aligned bounding boxes (AABBs), one per light cluster, which are later used to efficiently cull and assign lights during rendering.

**Workgroup and Grid Configuration**

The shader is configured with a workgroup size of `16x9x1`, reflecting a screen-space tile layout that maps naturally to common display aspect ratios. It operates over a 3D cluster grid defined by two spatial dimensions (screen-space tiles) and one depth dimension (slices along the view frustum).

**Uniform and Storage Buffer Layout**

A `ClusterUniforms` uniform block provides all necessary configuration parameters, including:
- Tile pixel size (width and height of each screen tile)
- Grid dimensions (number of tiles in X, Y, and Z)
- Slice count, near plane, and far plane distances
- Screen resolution

A `ClusterBuffer` shader storage buffer object (SSBO) holds the output — a flat array of AABB structures, each containing a `min` and `max` point in view space. This buffer is written by the compute shader and consumed downstream by light-culling passes.

**Core Logic**

The shader's `main` function computes the AABB for each cluster by:
1. Mapping the current invocation's 3D grid index to screen-space tile corners.
2. Converting those screen-space corners to normalized device coordinates (NDC) using the `screenToView` helper function.
3. Computing per-slice depth bounds using the `sliceNear` function, which applies a logarithmic or linear depth partitioning scheme based on the near/far plane parameters.
4. Writing the resulting `min` and `max` extents into the flat-indexed cluster array within `ClusterBuffer`.

**Target Audience and Use Context**

This shader is intended for graphics programmers implementing clustered shading techniques in Vulkan-based renderers. Readers should be comfortable with:
- GLSL compute shader syntax and execution model
- Vulkan descriptor sets and buffer binding conventions
- Rendering concepts such as NDC space, view-space transformations, and frustum depth slicing
- Tile-based and clustered light culling architectures

It serves as a practical reference for anyone building or studying real-time rendering systems that need to scale efficiently with large numbers of dynamic lights.
