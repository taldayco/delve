This directory contains the complete source and reference documentation for **FastNoiseLite**, a lightweight, high-performance C++ procedural noise generation library. It covers the full implementation of multiple noise algorithms including OpenSimplex2, Perlin, Cellular (Worley), Value, and ValueCubic noise, along with fractal layering (FBm, Ridged, PingPong), domain warping, and extensive precomputed gradient/random vector lookup tables. Suitable for C++ developers, graphics programmers, and game developers building procedural terrain, textures, or simulation systems.
