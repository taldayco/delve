# FastNoiseLite.h

This directory contains the complete source and reference documentation for **FastNoiseLite**, a lightweight, high-performance C++ procedural noise generation library. It covers the full implementation of multiple noise algorithms including OpenSimplex2, Perlin, Cellular (Worley), Value, and ValueCubic noise, along with fractal layering (FBm, Ridged, PingPong), domain warping, and extensive precomputed gradient/random vector lookup tables. Suitable for C++ developers, graphics programmers, and game developers building procedural terrain, textures, or simulation systems.

## Detailed Description

### FastNoiseLite_1.md Public API and Core Configuration
Defines the `FastNoiseLite` class with all public enumerations and setter methods. Covers noise types, fractal modes, cellular distance functions, domain warp options, and the constructor defaults. Entry point for any developer integrating the library.

### FastNoiseLite_10.md Private Implementation and Math Utilities
Documents internal member variables, fractal/domain warp dispatch logic, and foundational math helpers including `FastFloor`, `Lerp`, `InterpHermite`, `InterpQuintic`, `CubicLerp`, `PingPong`, and prime-based hashing constants.

### FastNoiseLite_11.md Gradient Helpers and Noise Dispatch
Covers `GradCoord`, `GradCoordOut`, `GradCoordDual`, and the `GenNoiseSingle` dispatch template routing calls to specific algorithm implementations. Also documents `TransformNoiseCoordinate` for frequency scaling and OpenSimplex2 skewing.

### FastNoiseLite_12.md Coordinate Transforms and Fractal FBm/Ridged
Details 3D transform strategies (`ImproveXYPlanes`, `ImproveXZPlanes`, `DefaultOpenSimplex2`), domain warp transform selection, and fractal octave accumulation for FBm and Ridged noise types.

### FastNoiseLite_13.md Ridged, PingPong Fractals and 2D/3D OpenSimplex2
Implements `GenFractalRidged`, `GenFractalPingPong`, `SingleSimplex` (2D), and `SingleOpenSimplex2` (3D), covering octave layering, gradient sampling, skewing transformations, and radial falloff kernels.

### FastNoiseLite_14.md OpenSimplex2S (2D and 3D)
Low-level implementation of the OpenSimplex2S algorithm using floor-based grid indexing, mask-based neighbor selection, fourth-power attenuation, and prime hashing for smooth, high-quality noise output.

### FastNoiseLite_15.md 3D OpenSimplex2 Completion and 2D Cellular Noise
Finalizes the 3D simplex gradient accumulation and introduces `SingleCellular` (2D) with Euclidean, Manhattan, and Hybrid distance metrics, jitter modulation, and nearest-neighbor tracking.

### FastNoiseLite_16.md SingleCellular (2D and 3D) with Return Types
Full implementation of cellular noise for both 2D and 3D spaces, including all seven return type modes (CellValue, Distance, Distance2, Distance2Add/Sub/Mul/Div) and prime-based spatial hashing.

### FastNoiseLite_17.md 3D Cellular Completion, Perlin, and 2D ValueCubic
Completes 3D cellular distance/return logic, then implements 2D and 3D Perlin noise using quintic interpolation and gradient coordinates, plus 2D cubic value noise over a 4×4 grid.

### FastNoiseLite_18.md 3D ValueCubic and Standard Value Noise
Implements `SingleValueCubic` (3D) using a 4×4×4 lattice with nested `CubicLerp`, and `SingleValue` for 2D/3D using Hermite-interpolated bilinear and trilinear sampling.

### FastNoiseLite_19.md Domain Warp Dispatch and Fractal Warping
Documents `DoSingleDomainWarp`, `DomainWarpSingle`, `DomainWarpFractalProgressive`, and `DomainWarpFractalIndependent`, covering amplitude/frequency modulation across octaves and BasicGrid warp via Hermite interpolation.

### FastNoiseLite_2.md Domain Warp Internals: BasicGrid and 2D Simplex
Covers 2D/3D `SingleDomainWarpBasicGrid` using hash-based random vector lookups and Hermite smoothing, plus `SingleDomainWarpSimplexGradient` (2D) with gradient-only output mode.

### FastNoiseLite_20.md OpenSimplex2 Domain Warp (2D and 3D)
Implements `SingleDomainWarpOpenSimplex2Gradient` for both dimensions, using fourth-power falloff, `GradCoordOut`/`GradCoordDual`, sign-based neighbor traversal, and explicit float/double/long double template specializations.

### FastNoiseLite_21.md–FastNoiseLite_26.md 2D Gradient and Random Vector Lookup Tables
Define `Gradients2D` (unit circle vectors at 24 angular intervals) and `RandVecs2D` (precomputed normalized 2D random direction vectors) used for gradient noise hashing and domain warp displacement.

### FastNoiseLite_27.md–FastNoiseLite_8.md 3D Gradient and Random Vector Lookup Tables
Define `Gradients3D` (256-entry integer gradient table with 12 repeating directions) and `RandVecs3D` (normalized 3D unit vectors in x, y, z, 0 format with SIMD-friendly padding) for 3D gradient noise and domain warping.

### FastNoiseLite_9.md Header Guard Closing Directive
Contains only the closing `#endif` preprocessor directive, marking the end of the FastNoiseLite header guard. No standalone documentation value; relevant only in full-file context.
