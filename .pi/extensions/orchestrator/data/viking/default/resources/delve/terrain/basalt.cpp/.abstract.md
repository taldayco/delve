This directory contains the implementation of procedural basalt column terrain generation for a hexagonal grid-based terrain system. The source file `basalt.cpp` is documented across two reference files covering its core algorithms: plateau detection, BFS-based flood fill, Worley noise-driven column placement, and hex grid mathematics. The code integrates with SDL3, custom hex utilities, and palette/map data structures. It is suitable for intermediate-to-advanced C++ developers working on procedural terrain generation, game engines, or geological simulation tools.
