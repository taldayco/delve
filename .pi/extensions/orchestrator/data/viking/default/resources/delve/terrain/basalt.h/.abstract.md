This directory contains the C++ API reference for procedural basalt column terrain generation. It defines the core interfaces for creating hexagonal basalt column formations within a simulation or game terrain system, covering two generations of the API: a heightmap-driven approach and a newer Worley noise-parameterized implementation. Key topics include hexagonal grid modeling, heightmaps, plateau data, and noise-based procedural generation. Suitable for C++ game and simulation developers working on procedural terrain systems who are familiar with hexagonal grids and noise-based generation techniques.
