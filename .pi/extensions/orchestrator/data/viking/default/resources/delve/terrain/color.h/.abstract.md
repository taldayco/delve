This directory contains a single C++ header file providing lightweight, dependency-free utility functions for pixel-level color manipulation. It is designed for use in software renderers, procedural terrain and texture generation, and game engines. The file covers core operations including color interpolation, noise variation, darkening, alpha blending, color modulation, and hexagonal dithering. All colors are represented as 32-bit ARGB integers. It is best suited for C++ graphics developers who need fast, self-contained color utilities without external library dependencies.
