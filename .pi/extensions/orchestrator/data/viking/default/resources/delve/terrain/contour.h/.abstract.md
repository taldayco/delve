This directory contains a C++ header file providing a terrain analysis API focused on contour extraction and plateau detection from heightmap data. It covers core algorithms for processing float-based heightmap grids, generating elevation contour lines, simplifying geometric output, and identifying flat terrain regions with spatial metadata. The API is suitable for C++ developers building terrain rendering engines, GIS tools, procedural game map generators, or geographic visualization systems. Familiarity with C++ standard library features — particularly `std::span` and `std::vector` — is assumed.
