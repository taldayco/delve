This directory contains the implementation of a hexagonal grid coordinate system designed for terrain rendering in tile-based or strategy game engines. It covers bidirectional coordinate conversion between hex grid positions and pixel space, polygon corner generation, spatial hit detection, and visible edge computation for cliff and silhouette rendering. The module is built around flat-top hexagonal geometry and axial/cube coordinate mathematics. It is best suited for game engine developers and graphics programmers with familiarity in 2D geometry, hexagonal grid theory, and C++.
