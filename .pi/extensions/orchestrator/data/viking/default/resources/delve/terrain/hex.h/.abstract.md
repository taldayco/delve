This directory contains the header file defining the core API for a hexagonal grid system used in terrain rendering. It covers essential data structures and utility functions for hex-based coordinate management, geometry calculations, and edge visibility computation. Key topics include coordinate conversion between hex grid and pixel space, tile geometry, point-in-hex collision testing, and terrain column data modeling. The file is suited for game or simulation developers working with hexagonal tile-based terrain systems who have familiarity with 2D geometry, grid coordinate systems, and C++.
