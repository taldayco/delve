## Detailed Description

### hex.md hex.md — Hexagonal Grid API Reference

This header file defines the foundational data structures and utility functions powering a hexagonal grid terrain rendering system. It serves as the primary API reference for developers integrating hex-based coordinate management and tile geometry into a game or simulation.

#### Data Structures

- **`HexColumn`**: The central terrain data structure representing a single column in the hex grid. It stores the column's grid position, height values, edge visibility flags, and edge drop data, making it the primary carrier of per-tile terrain information.

- **`HexCoord`**: A lightweight coordinate pair identifying a position in the hex grid. Includes an equality comparison operator, making it straightforward to compare grid positions directly.

- **`HexHash`**: A hashing utility struct that enables `HexCoord` values to be used as keys in unordered containers such as `std::unordered_map` and `std::unordered_set`, supporting efficient spatial lookups.

#### Core Functions

- **`hex_to_pixel`**: Converts a hex grid coordinate into pixel (screen) space. Essential for rendering hex tiles at the correct screen position.

- **`pixel_to_hex`**: Performs the reverse conversion, mapping a pixel position back to the corresponding hex grid coordinate. Useful for mouse picking and input handling.

- **`get_hex_corners`**: Returns the six corner vertices of a hex tile given its grid position. Used for rendering tile geometry, drawing outlines, or performing geometric calculations.

- **`pixel_in_hex`**: Tests whether a given pixel coordinate falls within the bounds of a specific hex tile. Supports hit-testing and collision detection in screen space.

- **`compute_visible_edges`**: Determines which edges of a hex tile should be rendered as visible, based on neighboring tile data. This is key to producing clean terrain visuals by avoiding rendering of hidden or interior edges.

#### Dependencies and Context

The file depends on core type definitions and terrain utilities from elsewhere in the project, meaning it is designed to integrate into a larger codebase rather than function as a standalone module. Developers using this header should be comfortable with hexagonal grid theory (offset or axial coordinates), basic 2D geometry, and modern C++ container usage.

#### Intended Audience

This file targets game or simulation developers building hexagonal tile-based terrain systems. It is particularly relevant for those working on rendering pipelines, terrain editors, or spatial query systems where hex grid geometry is central to the design.
