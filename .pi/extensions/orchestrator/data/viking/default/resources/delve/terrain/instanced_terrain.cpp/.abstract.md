This directory contains the implementation of GPU-accelerated instanced rendering for hexagonal terrain columns in a tile-based game engine. It covers the full pipeline from CPU-side instance data construction to GPU buffer upload and resource cleanup, using SDL_GPU, GLM, and palette-driven color assignment. Core keywords include instanced rendering, SSBO, hex terrain, SDL_GPU, GLM, ColumnInstance, and GPU buffer management. The file is suitable for graphics programmers and game engine developers familiar with C++, OpenGL/SDL_GPU workflows, and hexagonal grid systems who need a reference implementation for terrain rendering pipelines.
