This directory contains the header file and documentation for the `InstancedTerrain` system, a C++ GPU-accelerated rendering component designed for hexagonal terrain visualization. It covers instanced rendering of hex columns using SDL3's GPU API and GLM math, including GPU buffer management via Shader Storage Buffer Objects (SSBOs). The content is aimed at graphics programmers and game engine developers familiar with C++, instanced rendering pipelines, SDL3, and GLM. Core topics include the `ColumnInstance` data structure, GPU buffer uploads, CPU-side instance data manipulation, and hexagonal terrain state integration.
