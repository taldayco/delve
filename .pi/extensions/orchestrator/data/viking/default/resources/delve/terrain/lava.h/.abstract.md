This directory contains the header file defining the API for a procedural lava and void terrain generation system in C++. It covers core data structures for mesh geometry, spatial region representation, and flood-fill-based simulation of lava bodies on grid-based maps. Key concepts include flood fill algorithms, procedural terrain generation, renderable mesh data, and void region detection. The content is suitable for intermediate to advanced C++ developers working on game engines, simulation tools, or procedural map generation pipelines who need to integrate or extend lava terrain systems.
