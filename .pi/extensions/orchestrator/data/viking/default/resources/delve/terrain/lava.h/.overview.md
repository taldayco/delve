## Detailed Description

### lava.md lava.md — API Reference: Lava and Void Terrain Generation

This file documents the full public interface defined in `lava.h`, serving as the primary reference for developers integrating or extending the lava and void terrain generation system.

**Core Data Structures**

- **`LavaVertex`**: The foundational geometric primitive, storing a 2D position and a base elevation value. Used as the building block for constructing mesh geometry across the terrain grid.

- **`LavaMesh`**: Represents a renderable grid mesh composed of vertex data, index buffers, and active cell information. This structure bridges the terrain simulation with the rendering pipeline, making it directly usable for GPU-based mesh rendering or further geometric processing.

- **`LavaBody`**: The central region descriptor, encapsulating everything needed to represent a discrete lava area on the map. Fields include:
  - Spatial bounds defining the region's extent
  - Height value for the lava surface
  - Pixel membership data identifying which map cells belong to the body
  - Associated `LavaMesh` geometry for rendering
  - A time offset value supporting animation (e.g., flowing or pulsing lava effects)
  - A plateau association linking the lava body to broader terrain features

- **`FloodFillResult`**: A top-level container returned after a full map processing pass. It holds two collections — one for identified lava bodies and one for void bodies — providing a unified result from a single generation call.

**Primary Function**

The key entry point is:

```cpp
FloodFillResult generate_lava_and_void(MapData& map, float voidProbability, std::optional<int> seed);
```

- **`map`**: A reference to the `MapData` structure representing the terrain to be processed.
- **`voidProbability`**: A float value controlling how frequently void regions are generated during the flood-fill pass, allowing developers to tune the density and distribution of empty or hollow terrain areas.
- **`seed`** *(optional)*: An integer seed for the random number generator, enabling reproducible terrain outputs useful for testing, debugging, or deterministic world generation.

The function returns a `FloodFillResult` containing all lava and void bodies identified across the map.

**Usage Context**

This API is designed for use within a larger procedural map generation pipeline. Developers would typically call `generate_lava_and_void` after initial terrain heightmap generation, using the resulting `FloodFillResult` to populate scene geometry, drive rendering passes, or feed downstream simulation systems. The separation of lava bodies and void bodies within the result allows each type to be handled independently by different subsystems.
