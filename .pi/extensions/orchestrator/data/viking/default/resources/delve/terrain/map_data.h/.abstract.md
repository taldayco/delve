This directory contains the core header file for a procedural terrain generation system built on a hex-based map architecture. It defines the foundational `MapData` structure used to organize and manage multiple layers of terrain data, including elevation, liquid simulation, noise inputs, and spatial grid structures. The file is essential for developers building or extending a game engine or simulation framework that relies on procedural world generation. Familiarity with C++, Worley noise, hex grid systems, and fluid simulation concepts is recommended. Key topics include terrain generation, lava bodies, contour lines, elevation mapping, and liquid masking.
