## Detailed Descriptions

### map_util.md map_util.md

This file documents the full implementation of four terrain utility functions that together form the spatial query backbone of a hex-grid world system.

**`sample_world_height`**
Performs bilinear interpolation on a basalt height map using world-space coordinates. Input coordinates are scaled by `HEX_SIZE` to map from world units into pixel-space on the height map texture or grid. This function is the foundational building block for all height-dependent queries in the system.

**`sphere_trace_height`**
Extends basic height sampling by evaluating eight evenly distributed perimeter points around a given radius, in addition to the center point. It returns the maximum height found across all sampled points, effectively computing the ground clearance needed for a sphere of a given radius to rest on the terrain without clipping. This is particularly useful for physics placement and collision avoidance.

**`sample_terrain_normal`**
Computes the surface normal at a given world position using a central-difference gradient approximation — sampling height at small offsets in the X and Z axes and deriving the perpendicular vector from the resulting slope. The output is suitable for use in lighting calculations, surface-aligned object placement, or physics response systems.

**`find_spawn_column`**
Implements a BFS-based connected component analysis over the hex column grid to identify a suitable spawn location. The algorithm traverses neighboring hex columns, groups them into contiguous regions, identifies the largest connected region, and selects a random tile from within it using a seeded RNG. This ensures spawns land in open, accessible areas rather than isolated or unreachable map fragments. Key concepts exercised here include hex neighbor offset tables, graph traversal over `HexColumn` data structures, and reproducible randomness via seeded generation.

**Supporting Concepts Covered**
- Hex coordinate neighbor offsets and adjacency rules
- World-to-pixel coordinate mapping via `HEX_SIZE` scaling
- Bilinear interpolation mechanics on a 2D grid
- Central-difference numerical differentiation for normals
- Connected component labeling via BFS on irregular grids
- Seeded RNG for deterministic procedural placement
