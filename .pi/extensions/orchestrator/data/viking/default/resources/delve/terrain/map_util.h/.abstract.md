This directory contains the `map_util.h` header file, a C++ API providing terrain sampling and spawn utility functions for a hex-based map system. It is built around `MapData` structures and leverages GLM for vector mathematics, alongside custom hex and terrain modules. The file covers bilinear height interpolation, sphere-based terrain contact approximation, surface normal computation, and spawn location selection via connected component analysis. It is best suited for game engine or simulation developers working with hexagonal terrain systems who are comfortable with world-space coordinate systems, C++ graphics programming, and spatial math concepts.
