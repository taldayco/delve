# map_util.h

This directory contains the `map_util.h` header file, a C++ API providing terrain sampling and spawn utility functions for a hex-based map system. It is built around `MapData` structures and leverages GLM for vector mathematics, alongside custom hex and terrain modules. The file covers bilinear height interpolation, sphere-based terrain contact approximation, surface normal computation, and spawn location selection via connected component analysis. It is best suited for game engine or simulation developers working with hexagonal terrain systems who are comfortable with world-space coordinate systems, C++ graphics programming, and spatial math concepts.

## Detailed Descriptions

### map_util.md map_util.md — Terrain Sampling & Spawn Utility API Reference

This header file defines four core utility functions that operate on `MapData` structures, forming the primary interface for querying and interacting with hex-based terrain at runtime.

**`sample_world_height`**
Performs bilinear interpolation of basalt height data at a given world-space coordinate. This function gracefully handles missing or empty data by returning `0.0f`, making it safe to call even in partially initialized map states. It is the foundational sampling primitive used by other functions in the file.

**`sphere_trace_height`**
Approximates terrain contact for spherical objects by sampling a disc of nine points around the query position and returning the maximum height encountered. This approach provides a practical and efficient solution for physics or collision queries where a single point sample would be insufficient — for example, when placing or moving a rounded object on uneven terrain.

**`sample_terrain_normal`**
Computes surface normals using central-difference methods, producing accurate terrain orientation vectors suitable for lighting calculations, object alignment, or slope-based gameplay logic. This function complements `sample_world_height` by providing directional surface information rather than scalar height values.

**`find_spawn_column`**
Identifies an optimal spawn location for a player or entity by selecting a random column from the largest connected component in the map. This ensures spawns are placed in meaningful, accessible areas of the terrain rather than isolated or degenerate regions, supporting robust game initialization and respawn logic.

**Dependencies and Integration**
The file depends on:
- **GLM** — for vector and math types used across all function signatures
- **Custom hex module** — providing `HexColumn` and hexagonal coordinate utilities
- **Custom map_data module** — supplying the `MapData` terrain structure that all functions consume
- **Standard integer types** — for index and size handling

This header is intended for developers integrating terrain queries into a game engine or simulation loop, and assumes familiarity with world-space coordinate conventions, bilinear sampling techniques, and C++ graphics or game programming patterns.
