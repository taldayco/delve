This directory contains the implementation of a procedural terrain heightmap generation system written in C++. It covers multi-octave fractal noise synthesis, gradient-based erosion simulation, boundary padding, value normalization, discrete terracing, and flood-fill region merging. The system leverages OpenSimplex2 noise via the FastNoiseLite library to produce naturalistic, game-ready terrain heightmaps. It is best suited for intermediate to advanced C++ developers working on procedural generation pipelines, game engines, or simulation systems who have foundational knowledge of noise algorithms, fractal techniques, and basic image processing concepts.
