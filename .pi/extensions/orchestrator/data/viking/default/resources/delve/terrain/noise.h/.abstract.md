A C++ header-only API for procedural noise-based terrain generation. This directory contains the interface definition for a heightmap generation system built on fractal Brownian motion (fBm) noise with terracing support. It exposes a clean configuration struct and a single generation function, making it straightforward to integrate into game engines, simulations, or any C++ application requiring procedural terrain. Suitable for C++ game developers and simulation engineers familiar with C++20 features, fractal noise concepts, and heightmap-driven terrain pipelines. Core keywords: procedural generation, heightmap, fractal noise, fBm, terrain, octaves, lacunarity, C++20.
