This directory contains the `noise_cache.h` C++ header file, which provides a caching layer for procedural noise generation in terrain and world-building systems. It defines the `NoiseCache` structure, enabling developers to store and retrieve previously computed noise results across three terrain-relevant slots — elevation, river, and Worley noise — using FNV-1a parameter hashing for cache validation. Suitable for C++ developers working on procedural generation pipelines who need to eliminate redundant noise computations and improve runtime performance.
