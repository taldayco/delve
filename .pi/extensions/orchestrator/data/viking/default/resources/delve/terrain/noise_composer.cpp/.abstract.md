This directory contains the implementation of a procedural terrain noise composition system written in C++. It serves as a core layer-blending module within a terrain engine, responsible for synthesizing multi-layer heightmaps from various noise sources including elevation, river masks, and Worley noise. Key topics include terracing, flood-fill region cleanup, Worley noise edge/cell outputs, parameter-based cache invalidation, and SDL3 integration. This material is best suited for intermediate to advanced C++ developers working on procedural terrain generation, game engines, or simulation systems.
