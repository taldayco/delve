## Detailed Descriptions

### noise_composer.md noise_composer.md — Terrain Noise Composition Implementation

This C++ source file is the central implementation of the terrain noise composition system. It defines two primary components that together form a complete procedural heightmap synthesis pipeline:

**`cleanup_small_regions` (Static Utility Function)**
This function performs flood-fill connected-component analysis across the heightmap to identify and eliminate small, isolated terrain regions. Regions that fall below a minimum size threshold are considered artifacts and are replaced with values averaged from their neighboring cells. This post-processing step ensures the final heightmap is free of visually distracting or logically inconsistent micro-regions that can arise from aggressive noise layering or terracing.

**`compose_layers` (Main Composition Function)**
This is the primary orchestration function that drives the full multi-layer terrain synthesis process. Its responsibilities include:

- **Elevation Layer Generation**: Produces the base heightmap by sampling and combining noise functions that define the broad topographic shape of the terrain.
- **River Mask Generation**: Generates a secondary mask layer used to carve or influence river channels across the terrain surface, enabling realistic drainage patterns.
- **Worley Noise Layer Generation**: Samples Worley (cell) noise to produce both edge-distance outputs and cell-value outputs, which are used to add organic variation, define biome boundaries, or enhance surface detail.
- **Parameter Scaling**: Normalizes and scales input parameters relative to the overall map dimensions to ensure consistent visual results regardless of map resolution or size.
- **Caching via `NoiseCache`**: Implements a hash-based caching mechanism that stores previously computed noise results keyed by their input parameters. Before performing any expensive noise computation, the system checks whether a matching cached result already exists, avoiding redundant work during iterative map generation or real-time editing workflows.

**Terracing**
After all noise layers are composed, the system applies a terracing pass that quantizes continuous elevation values into a fixed number of discrete levels. This produces the characteristic stepped appearance of terraced terrain, useful for stylized maps or strategy game environments.

**Region Cleanup**
Following terracing, `cleanup_small_regions` is invoked to remove small artifacts introduced by the quantization step, ensuring the final output is clean and suitable for downstream processing such as rendering, pathfinding, or biome assignment.

**Key Concepts Covered**
- Cache hashing for parameter-based invalidation
- Terrace level quantization of floating-point heightmap data
- Flood-fill connected-component analysis for region-size filtering
- Multi-layer noise blending and composition order
- SDL3 integration for heightmap surface management
