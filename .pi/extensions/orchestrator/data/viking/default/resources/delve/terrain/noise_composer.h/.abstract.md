This directory contains the header file defining the noise composition interface for a procedural terrain generation system in C++. It covers the core API for combining multiple noise layers into cohesive terrain map data, including configuration of elevation thresholds, river parameters, Worley noise, void regions, and terrain terracing. The module serves as the integration layer of the terrain pipeline, bridging individual noise layers with final map output. It is suitable for C++ game developers and simulation engineers familiar with procedural generation techniques and noise-based terrain synthesis.
