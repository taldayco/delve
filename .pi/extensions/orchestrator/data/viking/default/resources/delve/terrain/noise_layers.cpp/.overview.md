# noise_layers.cpp

This directory contains the implementation of a procedural terrain generation noise layer system in C++. The source file is documented across two summary files covering elevation heightmaps, river channel masks, Worley/cellular noise, and domain-warped multi-layer noise generation. The code leverages the FastNoiseLite library alongside custom parameter structs to produce realistic, compositable terrain data. It is suitable for intermediate to advanced C++ developers working on procedural world generation, game terrain systems, or texture synthesis pipelines who are familiar with noise algorithms and fractal techniques.

## Detailed Descriptions

### noise_layers_1.md noise_layers_1.md — Core Generation Functions: Elevation, River, and Worley Noise

This section documents the primary noise generation functions and their supporting utilities. Three main functions are defined:

- **`generate_elevation_layer`**: Uses multi-octave OpenSimplex2 noise with configurable lacunarity and gain to build a heightmap. A gradient accumulation mechanism simulates basic erosion, producing more naturalistic terrain features. Output is normalized to a standard range.

- **`generate_river_mask`**: Applies ridged fractal noise to carve river channel patterns into the terrain. The ridged technique inverts and folds noise values to create sharp, valley-like features characteristic of waterways.

- **`generate_worley_layer`**: Generates Worley (cellular) noise and separates results into three distinct output channels — cell value, edge distance, and cell identity — enabling flexible downstream compositing.

Supporting utilities include:

- **`seed_offset`**: Provides deterministic coordinate offsets derived from a seed value, ensuring reproducible variation across different terrain instances.
- **`biased_smoothstep`**: A customizable curve-shaping function that adjusts the bias of the standard smoothstep interpolation for fine-tuned blending control.

Key concepts covered include fractal octave layering, frequency scaling, lacunarity, gain, and gradient-based erosion simulation. The code depends on the FastNoiseLite library and custom parameter structs (`ElevationParams`, `RiverParams`, `WorleyParams`). This section is essential reading for developers who need to understand how individual terrain layers are constructed before they are composited together.

### noise_layers_2.md noise_layers_2.md — Multi-Layer Cellular Noise with Domain Warping

This section documents the cellular noise pipeline, focusing on how multiple FastNoiseLite generators are configured and combined to produce rich, multi-channel terrain or texture data across a 2D grid.

Key components covered include:

- **Domain Warp Layer**: Configured using OpenSimplex2 with progressive fractal warping. When warp amplitude is non-zero, input coordinates are distorted before being passed to the cellular noise generators, producing organic, flowing distortions in the output.

- **Three Cellular Noise Variants**, all using EuclideanSq distance functions:
  - **Distance (out_value)**: Measures proximity to the nearest cell point, producing smooth gradient fields.
  - **Edge Detection (out_edge)**: Uses the Distance2Sub metric to highlight boundaries between cellular regions, useful for coastlines, cracks, or vein patterns.
  - **Cell Identity (out_cell_value)**: Assigns a unique value per cell region, enabling region-based coloring or biome assignment.

- **Per-Channel Min-Max Normalization**: All three output arrays are independently normalized to the 0–1 range after generation, ensuring consistent downstream usage regardless of raw noise amplitude.

The separation of outputs into three independent channels is a key architectural decision, allowing each channel to be used, blended, or masked independently in a terrain or texture pipeline. Domain warping is applied conditionally, making it easy to toggle organic distortion on or off per use case.

This section is particularly relevant for developers building biome systems, texture generators, or any pipeline requiring spatially coherent region segmentation with well-defined boundaries.
