# noise_layers.h

This directory contains the C++ header file `noise_layers.h`, which defines a procedural noise generation API for terrain and map creation systems. It covers three core noise layer types — elevation (fractal), river masking, and Worley cellular noise — along with their configuration parameter structures and generation functions. The file is aimed at C++ developers building procedural terrain systems, game world generators, or geographic simulations, and assumes familiarity with noise algorithms, fractal Brownian motion, and domain warping techniques.

## Detailed Description

### noise_layers.md noise_layers.md — API Reference for Procedural Noise Layers

This file serves as the primary API reference for `noise_layers.h`, documenting three parameter structures and their corresponding generation functions.

**ElevationParams & `generate_elevation_layer`**
`ElevationParams` controls fractal noise generation for terrain height maps. Its configurable fields include:
- `frequency` — base spatial frequency of the noise
- `octaves` — number of fractal layers stacked
- `lacunarity` — frequency multiplier between octaves
- `gain` — amplitude scaling between octaves
- `seed` — random seed for reproducibility
- `s-curve bias` — applies an S-curve to smooth or sharpen transitions
- `map scale` — overall spatial scaling of the output

The `generate_elevation_layer` function consumes an `ElevationParams` instance and outputs a height map suitable for terrain mesh generation or heightfield rendering.

**RiverParams & `generate_river_mask`**
`RiverParams` extends the fractal noise configuration with an additional `threshold` parameter, which defines the cutoff value used to carve river channels from the noise field. The `generate_river_mask` function produces a binary or continuous mask identifying river channel regions, making it useful for waterway placement, erosion simulation, or biome boundary definition.

**WorleyParams & `generate_worley_layer`**
`WorleyParams` configures Worley (cellular) noise generation with domain warping support. Its fields cover:
- `warp amplitude` — strength of the domain distortion applied before sampling
- `warp frequency` — spatial frequency of the warping noise
- `warp octaves` — fractal depth of the domain warp

The `generate_worley_layer` function is notable for producing **three simultaneous outputs**:
1. **Cell value map** — the raw Worley noise field
2. **Edge detection map** — highlights boundaries between Voronoi cells
3. **Per-cell value map** — assigns a unique or derived value to each discrete cell

This multi-output design makes it well-suited for generating rock formations, biome regions, cracked terrain surfaces, or any feature requiring cell-based spatial partitioning.

**Key Concepts Covered**
- *Fractal Brownian Motion (fBm)* — layering multiple octaves of noise at increasing frequencies and decreasing amplitudes
- *Worley / Cellular Noise* — distance-field-based noise producing organic, cell-like patterns
- *Domain Warping* — distorting the input coordinate space before noise sampling to produce flowing, turbulent results
- *Multi-output Noise Layering* — generating several semantically distinct maps from a single noise pass for efficiency and coherence

This header is the foundational building block for any procedural world generation pipeline built on this codebase, and should be the first reference point for developers integrating or extending the noise system.
