This directory contains a C++ header file implementing a color palette system designed for elevation-based terrain and map rendering. It provides data structures and utility functions for mapping normalized elevation float values to RGBA colors, supporting both discrete stepped and smooth gradient rendering modes. The system is built around a flexible `Palette` struct and includes predefined palette constants. It is suitable for C++ graphics developers, game developers, and anyone working on procedural terrain generation, map visualization, or elevation-driven rendering pipelines.
