This directory contains the implementation of a procedural terrain generation pipeline built with C++ and SDL3. It focuses on volcanic and geological terrain synthesis, covering the full generation sequence from heightmap input through plateau detection, basalt column placement, channel extraction, lava flow filtering, and final terrain map composition. The codebase is suitable for engine developers, game programmers, and technical artists working on procedural world-building systems, particularly those involving volcanic or geologically complex environments. Familiarity with C++ spans, SDL3, and procedural generation concepts is recommended.

## Detailed Descriptions

### terrain_generator.md terrain_generator.md — Core Terrain Generation Pipeline

This file documents the central implementation of the procedural terrain generation system. The primary entry point is `TerrainGenerator::generate`, a function that accepts a **heightmap** and a **band map** as inputs and returns a fully composed `TerrainData` structure.

The generation process follows a clearly defined **sequential pipeline**:

1. **Plateau Detection** — Elevated plateau regions are identified by analysing the heightmap in combination with the band data. Only qualifying regions proceed to subsequent stages.

2. **Basalt Column Placement** — Procedural basalt columns are placed across detected plateaus. Column generation is governed by a configurable hex size parameter, allowing density and scale to be tuned per use case.

3. **Channel Extraction** — Open channel spaces between terrain features are extracted. These represent the gaps and corridors left between placed columns and other terrain geometry.

4. **Lava Flow Filtering** — Extracted channels are evaluated against validity criteria to identify which paths are suitable for lava flow. Invalid or disconnected channels are discarded at this stage.

5. **Lava Body Conversion** — Channels that pass filtering are converted into lava body objects. Their corresponding pixel indices are written into the terrain map and marked with the `TERRAIN_LAVA` designation, completing the terrain composition.

Throughout each stage, **SDL3 logging statements** emit diagnostic output reporting counts of plateaus found, columns placed, channel regions extracted, and lava bodies finalised. This makes the pipeline straightforward to debug and profile during development.

**Key dependencies** include:
- Terrain-specific modules for basalt generation and lava body construction
- A global configuration header governing shared parameters
- SDL3 for cross-platform logging support

This file is the primary reference for developers integrating or extending the terrain generation system, and serves as the authoritative description of how raw elevation data is transformed into a richly composed volcanic terrain output.
