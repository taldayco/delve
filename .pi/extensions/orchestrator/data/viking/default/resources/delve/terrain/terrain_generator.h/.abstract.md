This directory contains the header file for the `TerrainGenerator` class, a C++ API for procedural terrain generation in hex-based or grid-based game and simulation environments. It covers heightmap-driven terrain synthesis, plateau identification, lava body generation, and hexagonal column mapping. The API is designed for C++ game developers and engine programmers who need to integrate procedural terrain systems into their projects, and requires familiarity with modern C++ features such as `std::span` and `std::vector`.
