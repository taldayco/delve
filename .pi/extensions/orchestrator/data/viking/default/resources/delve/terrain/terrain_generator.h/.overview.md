## Detailed Description

### terrain_generator.md terrain_generator.md — TerrainGenerator API Reference

This file is the API reference documentation for the `TerrainGenerator` C++ header. It defines a single class, `TerrainGenerator`, which exposes a static `generate()` method as its primary interface. The method accepts the following inputs:

- **Heightmap** (`float` span): A floating-point span representing elevation data across the terrain grid.
- **Band map** (`int` span): An integer span used to classify terrain bands or zones.
- **Grid dimensions** (`width` and `height`): Integer values defining the size of the terrain grid.

The method returns a `TerrainData` struct, which bundles all generated terrain components into a single output object. The components encapsulated within `TerrainData` include:

- **Plateaus**: Flat elevated regions identified from the heightmap.
- **Hex columns**: Hexagonal column structures mapped across the grid.
- **Lava bodies**: Generated lava regions derived from terrain topology.
- **Plateau-column associations**: Mappings that link plateaus to their corresponding hex columns.
- **16-bit terrain map**: A compact binary representation of the full terrain layout.

The file also documents the class's dependencies on terrain contour and map data headers, indicating that `TerrainGenerator` is designed to operate as part of a larger, modular terrain pipeline rather than as a standalone utility. Developers integrating this class should ensure that the broader terrain system headers are available and properly linked.

This reference is best suited for C++ game developers or engine programmers who are building or extending procedural terrain systems. A working knowledge of modern C++ — particularly `std::span` for non-owning views over contiguous data and `std::vector` for managing generated output collections — is assumed. The static design of the `generate()` method means no class instantiation is required, making it straightforward to call from any context within the engine or game logic layer.
