# terrain_mesh.h

This directory contains the core header file for a tile-based 3D terrain rendering system written in C++. It defines the GPU-facing data structures, vertex formats, and function interfaces required to build and render terrain meshes with multiple surface types including basalt rock, animated lava, and contour lines. The file targets graphics programmers working with OpenGL or Vulkan pipelines and relies on GLM for mathematics. It is suitable for developers building or extending terrain visualization systems who need a clear API contract for mesh construction and shader uniform assembly.

## Detailed Description

### terrain_mesh.md terrain_mesh.md

This C++ header file defines the complete data structures and function interfaces for terrain mesh generation and GPU rendering in a 3D terrain visualization system. It covers three distinct vertex formats tailored to different surface types:

- **Basalt rock layers** — vertices include position, color, sheen intensity, and normal vectors, supporting the visual appearance of layered geological surfaces.
- **Lava surfaces** — extend the base vertex format with animated time offsets, enabling dynamic, time-driven surface animation in shaders.
- **Contour lines** — a lightweight vertex format dedicated to rendering elevation contour geometry overlaid on the terrain.

The `SceneUniforms` struct serves as the central per-frame shader parameter block, encapsulating:
- View and projection matrices for camera transformation
- Lighting configuration for scene illumination
- Lava color parameters for surface appearance
- Starlight contribution for ambient environmental lighting
- Grid dimensions for tile-based layout management
- Clipping planes for view frustum and sectional rendering

The `GpuPointLight` struct defines a std430-compatible, 32-byte aligned structure for dynamic point lights, ensuring correct memory layout when passed directly to GPU buffers in both OpenGL shader storage blocks and Vulkan descriptor sets.

The `TerrainMesh` struct organizes all terrain geometry into a coherent rendering pipeline structure, separating geometry into layered basalt rendering passes alongside dedicated lava and contour geometry buffers. This separation supports multi-pass rendering strategies where different surface types require different shaders or render states.

Two key functions are declared in this header:

- **`build_terrain_mesh`** — constructs the full terrain mesh from terrain state, map data, and contour data inputs, producing a populated `TerrainMesh` ready for GPU upload.
- **`compute_uniforms`** — assembles the complete `SceneUniforms` block from current scene state, preparing it for direct consumption by shaders.

This is a reference-style API header designed for graphics programmers integrating terrain rendering into larger engine or visualization pipelines using modern GPU APIs with GLM math support.
