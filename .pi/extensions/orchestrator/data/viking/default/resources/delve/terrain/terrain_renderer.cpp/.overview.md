# terrain_renderer.cpp

This directory contains the full implementation of a GPU-accelerated terrain rendering system built on SDL3's GPU API using SPIR-V shader pipelines. It covers initialization, pipeline construction, mesh uploading, clustered forward lighting, light culling compute passes, render pass management, and resource cleanup. The codebase integrates GLM for math, a custom AssetManager for shader and pipeline lifecycle management, and supports PBR, instanced, lava, and contour rendering paths. Suitable for graphics engineers and game engine developers with intermediate-to-advanced knowledge of GPU APIs, compute shaders, and C++ systems programming.

## Detailed Descriptions

### terrain_renderer_1.md terrain_renderer_1.md — Initialization and Core Pipeline Setup
Covers the top-level `init` function, depth-stencil format negotiation, and the `build_compute_pipeline` helper for loading SPIR-V shaders. Establishes the renderer's foundational state including graphics, instanced, PBR, and compute sub-pipelines, and creates a dummy SSBO fallback buffer for shader binding safety.

### terrain_renderer_10.md terrain_renderer_2.md — Terrain, Lava, and Contour Pipeline Vertex Layouts
Details vertex buffer descriptions and attribute layouts for the terrain (`BasaltVertex`) and lava (`GpuLavaVertex`) pipelines, including depth-stencil state differences (`LESS_OR_EQUAL` vs `LESS`) and shader ownership delegation to the AssetManager.

### terrain_renderer_11.md terrain_renderer_3.md — Contour, Compute, and Instanced Pipeline Initialization
Covers the contour line pipeline with alpha blending and disabled depth testing, compute pipeline loading for cluster generation and light culling, and the beginning of the instanced terrain pipeline setup.

### terrain_renderer_12.md terrain_renderer_4.md — Instanced and PBR Pipeline Configuration
Details vertex buffer layouts for `GltfVertex` (48-byte stride) and `BasaltVertex`, attribute bindings for position/normal/color/sheen, and depth-stencil configuration for both the instanced terrain and PBR static pipelines.

### terrain_renderer_13.md terrain_renderer_5.md — PBR Pipeline Creation and Hot-Reload
Covers full `SDL_GPUGraphicsPipelineCreateInfo` configuration for the PBR terrain pipeline and the `rebuild_dirty_pipelines` method, which detects shader changes via the AssetManager, waits for GPU idle, and reconstructs pipelines using a lambda-based builder pattern.

### terrain_renderer_14.md terrain_renderer_6.md — Terrain and Lava Pipeline Construction
Documents the SDL GPU pipeline construction for solid terrain and lava surfaces, including shader loading, vertex attribute mapping with `offsetof`, swapchain color targets, and depth-stencil configuration for both pipeline variants.

### terrain_renderer_15.md terrain_renderer_7.md — Contour and Instanced Pipeline GPU Setup
Details the contour line pipeline (line-list primitives, alpha blending, depth disabled) and the instanced terrain pipeline (triangle-list, depth enabled, two FLOAT3 attributes), including shader bindings for uniforms and samplers.

### terrain_renderer_2.md terrain_renderer_8.md — PBR Pipeline and Cluster Buffer Initialization
Covers PBR pipeline construction with `BasaltVertex` layout, conditional hot-reload of `cluster_gen` and `light_culling` compute pipelines with GPU idle synchronization, and initialization of `cluster_aabb_ssbo` and `light_grid_ssbo` sized by tile grid and depth slice dimensions.

### terrain_renderer_3.md terrain_renderer_9.md — Cluster Lighting Buffers and Mesh Upload Setup
Documents creation of compute/graphics SSBOs (point lights, cluster AABB, light grid, global index, cull counter), AssetManager registration, and the `upload_mesh` function with a 128MB safety cap and multi-layer basalt index offset correction.

### terrain_renderer_4.md terrain_renderer_10.md — GPU Mesh Upload Pipeline
Details the single-pass staging buffer strategy for uploading basalt, lava, and contour mesh sections to the GPU, including offset calculation, `SDL_GPUCopyPass` execution, GPU idle synchronization, and AssetManager buffer registration.

### terrain_renderer_5.md terrain_renderer_11.md — glTF Column Mesh Upload and Instanced Draw
Covers safe GPU buffer lifecycle management for glTF column meshes, the `stage_instanced_draw` function binding instance SSBOs and clustered lighting buffers, and `upload_lights` with a maximum light count cap.

### terrain_renderer_6.md terrain_renderer_12.md — Light Upload Fallback and Cluster Grid Rebuild
Documents the fallback transfer buffer path for point light uploads, the cluster grid AABB rebuild triggered by resolution or tile size changes, and atomic counter reset before compute dispatch.

### terrain_renderer_7.md terrain_renderer_13.md — Light Culling Dispatch and Shaded Draw Stage
Details the `CullUniforms` struct (48 bytes), five SSBO bindings for the culling compute pass, 3D cluster grid dispatch, and the shaded draw stage with conditional paths for instanced terrain, basalt, lava, and contour rendering.

### terrain_renderer_8.md terrain_renderer_14.md — Render Pass Variants and Frame Entry Point
Covers three `begin_render_pass` variants (clear, load-color, load-both), dynamic depth texture creation and resizing in `prepare_frame_resources`, and the frame entry point orchestrating light upload, culling, and shaded draw.

### terrain_renderer_9.md terrain_renderer_15.md — GPU Resource Cleanup and Teardown
Documents `release_buffers`, `release_cluster_buffers`, and the full `cleanup` function, covering safe null-checked deallocation of all pipelines, textures, SSBOs, and dummy buffers with GPU idle synchronization.
