This directory contains the C++ header definition for the `TerrainRenderer` class, a GPU-accelerated terrain rendering system built on SDL3's GPU API. It covers multiple rendering pipelines (standard, instanced, PBR), clustered forward lighting with point light culling, mesh upload utilities, and GPU buffer management. The header is split across two reference documents detailing public API and internal state respectively. Suitable for graphics programmers and game engine developers with familiarity in GPU programming, clustered shading techniques, and real-time rendering pipelines.
