A focused C++ utility header providing fast, lightweight integer hashing functions for use in performance-critical applications. This directory contains a single header file implementing two core hash operations — 1D and 2D integer hashing — using non-cryptographic, multiplicative hashing techniques. Suitable for C++ developers working in game development, graphics programming, procedural content generation, or any domain requiring efficient spatial indexing or hash map operations. No external dependencies are required; only basic familiarity with C++ and bitwise arithmetic is assumed.
