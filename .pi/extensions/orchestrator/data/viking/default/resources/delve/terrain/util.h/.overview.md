## Detailed Descriptions

### util.md util.md — Integer Hashing Utility Header

This header file provides two inline hash functions designed for speed and simplicity in non-cryptographic contexts.

**`hash2d(int x, int y) → uint32_t`**
Accepts two integer coordinates and produces a single 32-bit unsigned integer hash. The function combines the two inputs using multiplicative constants and bitwise XOR operations to achieve good distribution and an avalanche effect — small changes in input produce significantly different outputs. This makes it well-suited for spatial hashing, such as mapping 2D grid coordinates to hash table buckets in procedural terrain generation or collision detection systems.

**`hash1d(int index) → uint32_t`**
Hashes a single integer using a similar multiplicative approach. Useful for sequential or arbitrary integer key hashing, such as indexing into procedurally generated data arrays or seeding pseudo-random number generators based on position or ID.

**Design Highlights:**
- Both functions are marked `inline`, minimizing call overhead in tight loops or real-time rendering pipelines.
- Prime-like multiplicative constants are chosen to encourage bit mixing and reduce clustering in hash distributions.
- No heap allocation, branching, or external dependencies — purely arithmetic operations on primitive types.
- The `uint32_t` return type ensures consistent, platform-independent output width.

**Typical Use Cases:**
- Procedural content generation (e.g., deterministic noise, world seeding)
- Spatial hash maps for 2D grid-based data structures
- Game development utilities requiring fast, repeatable hashing
- Graphics shaders or CPU-side preprocessing pipelines

**Prerequisites:** Basic C++ syntax, understanding of bitwise XOR (`^`), and familiarity with unsigned integer arithmetic (`uint32_t`).
