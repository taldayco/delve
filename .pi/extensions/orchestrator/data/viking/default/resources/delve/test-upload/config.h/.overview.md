# config.h

This directory contains the central configuration header for a hex-based map rendering and procedural generation application written in C++. It serves as the single source of truth for all global constants, default parameters, and tunable settings used throughout the system. Topics covered include window and UI layout dimensions, hexagonal map geometry, terrain generation parameters, procedural noise settings, and isometric rendering visuals. This directory is suitable for C++ game developers, simulation engineers, or technical artists working on hexagonal terrain visualization systems who need a clear reference for application-wide defaults and compile-time constants.

## Detailed Description

### config.md config.md — Central Application Configuration Header

This file defines a single `Config` struct that consolidates all global constants and default settings for the hex-based map rendering application. It is organized into several logical groups, each targeting a distinct aspect of the system:

**Window and UI Dimensions**
Defines the base window size and UI panel width, including responsive percentage-based sizing values. These settings control the overall layout of the application's graphical interface and ensure consistent proportions across different display contexts.

**Map Geometry**
Specifies the hexagonal grid dimensions (1024×1024 cells), individual hex cell size (8.0 units), and world unit scaling factors. These constants establish the spatial foundation of the map and are used throughout the rendering and simulation pipeline to correctly position and size hex cells.

**Terrain Parameters**
Contains thresholds and spacing values governing terrain feature generation, including lava grid spacing, height cutoff thresholds, and minimum plateau size. These values directly influence how terrain features are classified and rendered, making them key targets for gameplay or simulation tuning.

**Procedural Noise Generation Defaults**
Provides default values for the noise generation system, including scale, octave count, lacunarity, gain, seed, and quantization levels. These parameters control the character and detail of procedurally generated terrain, allowing developers to reproduce specific landscapes via the seed value or adjust visual complexity through octaves and lacunarity.

**Rendering and Visual Settings**
Defines isometric height scale, gradient scale, background color, lava color, and contour line opacity. These settings govern the final visual appearance of the rendered map and can be adjusted to achieve different aesthetic styles or improve readability.

**Implementation Notes**
The file makes deliberate use of both `static inline` mutable variables for runtime-adjustable values and `constexpr` for fixed compile-time constants. This distinction allows certain parameters to be modified during application execution (e.g., via a settings panel) while keeping performance-critical or structurally fundamental values locked at compile time. This design pattern makes `config.h` both flexible for interactive tuning and reliable as a stable foundation for the rest of the codebase.
